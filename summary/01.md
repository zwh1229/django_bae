什么是web应用程序？
用python写的就是一个应用程序，那么web应用程序呢 客户端是一个浏览器

三个步骤
1.一个http请求，获取信息
2.处理本次的请求，完成本次的请求业务逻辑处理
3.构造并返回处理结果 http响应



django里 要记命令 
创建项目
django-admin startproject 加文件名 如果和主应用同名 
生成后  
启动项目
执行manage.py  
python manage.py runserver ip Port



django 创建子应用

python manage.py startapp 子应用名称

目录
manage.py  用来启动服务器，数据库迁移，创建超级用户的命令入口
django_base  主应用，保存了项目中所有代码
    asgi   异步模式的web应用对象
    settings.py 默认开发配置文件
    urls.py     路由列表目录，用于绑定视图和url的映射关系
    wsgi        wsgi就是项目运行在wsgi服务器时的入口文件
    __init__.py

app01  子应用
    models 子应用的模型类  数据库的
    views  视图模块 处理逻辑数据库
    tests 单元测试模块
    apps 该应用的配置，自动生成
    admin.py 该应用的后台管理系统配置



render
功能：帮你把 模板（HTML 文件）+ 数据（字典） 渲染成一个完整的 HTML 页面，并返回给浏览器。
HttpResponse
功能：直接返回一段 字符串响应，不经过模板引擎。

manage 主项目等 放在根目录
